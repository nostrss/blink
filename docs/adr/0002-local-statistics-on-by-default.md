# 통계는 기본으로 켜고, Mac 안에만 둔다

1.3.0부터 입력소스 전환 횟수와 포인터 사용량(이동 거리, 움직인 시간, 클릭, 스크롤)을 센다. 권한 없이 받을 수 있는 것만 세고, 무엇을 입력했는지(키 내용·순서)는 세지 않는다. 기록은 샌드박스 컨테이너의 Application Support에 파일로만 두고 Mac 밖으로 보내지 않으므로 App Store 개인정보 항목은 "수집 안 함"을 유지한다. (2026-10-28 결정)

'통계 모으기'는 기본 켜짐이다. 꺼 두면 대부분의 사용자는 메뉴 맨 위의 통계 카드를 한 번도 보지 못하고, 나중에 켜도 그전 기록이 없다. 대신 설정 '통계'에서 끄고 '모두 지우기'로 기록을 지울 수 있게 하고, 무엇을 세는지 안내 한 줄을 둔다. 끄면 새로 세지 않을 뿐 기존 기록은 남는다.

보관 형식은 한 시간마다 합계 칸 하나(90일)와 하루 합계(계속)다. 오늘 시간별 막대와 7일·30일 비교에는 시간 칸이면 충분하고, 하루 합계는 나중의 '전체' 기간용이다. 출시하면 이 형식으로 쌓인 기록을 계속 읽어야 하므로 바꿀 때는 이전 형식을 읽는 코드를 남긴다.

입력소스별·앱별 사용 시간은 세지 않는다. Mac은 자리를 비운 시간을 알 수 없어 숫자가 부정확하다.
