# 타이핑 통계는 켤 때만 입력 모니터링 권한을 묻는다

1.4.0부터 키 입력 횟수와 분당 키 입력을 입력소스별·앱별로 센다. 이 값은 다른 앱에서 누른 키를 받아야 셀 수 있어서, Blink가 처음으로 시스템 권한(입력 모니터링)을 쓴다. 앱 샌드박스는 그대로 두고(ADR 0001), 리슨 전용 이벤트 탭(`CGEventTap` listenOnly)만 쓴다. 손쉬운 사용 권한은 쓰지 않는다. (2026-10-30 결정)

'타이핑 통계'는 기본 꺼짐이다. 통계 모으기(ADR 0002)는 권한이 필요 없어 기본 켜짐이지만, 권한 창을 처음 실행에 띄우면 무엇을 위한 권한인지 모른 채 거부하거나 앱을 의심하게 된다. 그래서 사용자가 설정 '통계'의 스위치나 메뉴·통계 창의 켜기 카드를 누를 때만 묻는다. 꺼져 있는 동안 기능이 있는지 알 수 있게 타이핑 자리에 켜기 카드를 늘 둔다.

키 코드는 읽지 않고, 반복 입력인지만 본다. 기록에는 개수, 타이핑한 시간, 그때의 입력소스 ID와 앱 번들 ID만 들어간다. 그래서 App Store 개인정보 항목은 "수집 안 함"을 유지한다. 완성된 글자 수를 세려면 입력한 글을 읽어야 해서 누른 키 기준으로 센다. 앱별은 하루 단위로만 남겨 기록이 커지지 않게 한다.

스위치를 끄면 탭을 바로 내린다. 권한은 시스템 설정에서만 거둘 수 있어, 끈 뒤 권한이 남아 있으면 권한 줄과 안내를 남긴다.
