# 1.3.0 한국어 메타데이터

App Store Connect에서 언어를 한국어로 두고 붙여 넣는 문안. 섹션은 App Store Connect의 macOS 앱 버전 화면에 나오는 순서대로 적었고, 이름·부제는 '앱 정보' 화면이라 맨 끝에 둔다. 1.2.0과 달라진 곳은 스크린샷 표(통계 1장 추가), 프로모션 텍스트, 설명의 '할 수 있는 것' 통계 줄과 '개인정보', 이 버전의 업데이트 내용(새로 씀), 심사 노트(설정 화면 수, '1.3.0의 새 기능', 마지막 문단)다.

## 4. 이 버전에서 업그레이드된 사항 (4000자)

1.3의 새로운 기능
• 통계: 오늘 한/영을 몇 번 바꿨는지 메뉴 맨 위에서 바로 봅니다. '통계…'를 고르면 7일·30일 기록과 포인터 이동 거리, 평균 속도, 클릭, 스크롤까지 볼 수 있습니다.

• 정돈된 설정 창: 시스템 설정처럼 설정을 상자로 묶었습니다.
• 'Blink 정보'에서 새로운 기능을 볼 수 있고, 업데이트한 뒤에는 한 번 저절로 열립니다.

쓰던 설정은 그대로 이어집니다.

## 7. 앱 심사 정보 > 메모 (번역, 참고용, 입력 안 함)

`en-US/metadata.md`의 심사 노트를 옮긴 것이다.

Blink는 Dock 아이콘이 없는 메뉴바 앱입니다. 키보드 입력소스가 바뀔 때마다 화면에 짧은 HUD를 띄웁니다.

중요: HUD는 입력소스가 실제로 바뀔 때만 뜹니다. 심사용 Mac에 입력소스가 하나뿐이면 아무것도 뜨지 않으니 먼저 하나를 추가해 주세요.

1. 시스템 설정 > 키보드 > 입력 소스 > 편집…을 엽니다.
2. "+"를 눌러 한국어 > 2벌식(다른 언어도 됩니다)을 고르고 추가를 누릅니다.
3. Control-Space(또는 메뉴바의 입력 메뉴, 설정해 두었다면 지구본·Caps Lock 키)로 입력소스를 전환합니다.
4. "변경 전 → 변경 후"(예: "ABC → 2벌식")를 보여 주는 HUD가 화면 가운데에 1초 동안 뜹니다.

설정: 처음 실행하면 설정 창이 자동으로 열립니다. 그 뒤에는 메뉴바의 Blink 아이콘(•→)을 눌러 "설정…"(⌘,)을 고릅니다. 설정은 일반·위치·모양·포인터·통계 다섯 화면입니다.

1.3.0의 새 기능:
• 통계(기본 켜짐): 이 Mac 안에서 입력소스 전환 횟수와 포인터 사용량을 셉니다. 메뉴 맨 위에 오늘 전환 횟수와 시간별 막대가 보이고, "통계…"는 오늘·7일·30일 창을 엽니다. 포인터 사용량은 마우스 이벤트만 받는 NSEvent 전역 모니터(마우스 이동·드래그, 왼쪽·오른쪽 누름, 스크롤 휠)로 셉니다. 키보드 이벤트는 감시하지 않고 내용도 기록하지 않습니다. 거리는 CGDisplayScreenSize로 mm로 바꿉니다.
• 기록은 90일 동안 한 시간 합계, 그 뒤로는 하루 합계로 앱 샌드박스 컨테이너의 Application Support/Statistics.json에 남습니다. Mac 밖으로 나가지 않습니다. 설정 > 통계에서 모으기를 끄고 기록을 모두 지울 수 있습니다(확인 시트).
• Blink 정보에 이 버전의 새로운 기능이 나옵니다. 업데이트 후 첫 실행에 한 번 저절로 열리고, 새로 설치했을 때는 열리지 않습니다.

1.2.0부터 있는 것:
• macOS 26(Tahoe) 이상에서 기본 테마는 HUD, 설정 미리보기, 포인터 배지를 Liquid Glass(NSGlassEffectView)로 그립니다. 모양 > 테마 > 클래식은 예전 모습을 쓰며 macOS 26 이상에서만 목록에 보입니다.

1.1.0부터 있는 선택 기능(모두 기본 꺼짐):
• 모양 > 표시 방식 > 약자: 이름 대신 "EN" 같은 약자로 보여 줍니다.
• 일반 > Caps Lock HUD 표시: Caps Lock을 누르면 "⇪ 켜짐"·"⇪ 꺼짐"을 보여 줍니다. NSEvent.modifierFlags로 Caps Lock 상태만 읽고, 키 입력은 감시하지 않습니다.
• 포인터 > 포인터 옆 입력소스 표시: 마우스 포인터 옆에 현재 입력소스를 담은 작은 배지를 붙여 둡니다. 마우스 이동 이벤트(마우스 이벤트만 받는 NSEvent 전역 모니터)와 NSEvent.mouseLocation을 씁니다.

입력소스가 하나뿐이면 '위치' 화면에 HUD가 뜨지 않는다는 안내가 나옵니다.

로그인 시 실행은 SMAppService를 쓰며 기본 꺼짐이고, 사용자가 켤 때만 등록됩니다.

Blink는 App Sandbox에서 실행되고, 네트워크에 접속하지 않으며, 데이터를 수집하지 않고, 어떤 권한(손쉬운 사용, 입력 모니터링)도 요청하지 않습니다. Text Input Sources API로 현재 입력소스를, 위에 적은 대로 Caps Lock 상태, 포인터 위치, 마우스 이벤트를 읽습니다. 통계는 기기 밖으로 나가지 않으므로 App 개인정보 보호 답변은 "데이터를 수집하지 않음" 그대로입니다.
