# 1.0.0 한국어 메타데이터

App Store Connect에서 언어를 한국어로 두고 붙여 넣는 문안. 스크린샷은 아래 '스크린샷' 표의 순서대로 올린다.

## 이름 (30자)

Blink: 입력 언어 알림

## 부제 (30자)

한영 전환, 이제 눈으로 확인

## 키워드 (100자)

입력소스,한영키,자판,키보드,오타,한글,영문,메뉴바,IME,두벌식

## 프로모션 문구 (170자)

한영 전환이 제대로 됐는지 궁금한 순간, Blink가 화면에 바로 알려 줍니다. 위치와 디자인까지 내 취향대로 설정하세요.

처음 안에서 "유효하지 않은 문자" 오류가 나서 바꿨다(설명의 → 는 저장됐으니 원인은 다른 문자일 수 있다).

## 설명

Mac에서 한/영을 바꾸다 이런 적 없으셨나요?
hello를 쳤는데 "ㅗ디ㅣㅐ"가, 안녕하세요를 쳤는데 "dkssudgktpdy"가 나옵니다. 문장을 다 쓰고 나서야 알아채고, 지우고, 다시 칩니다.

Blink는 메뉴바에 조용히 있다가 입력 언어가 바뀌는 순간 "ABC → 두벌식"처럼 무엇에서 무엇으로 바뀌었는지 화면에 잠깐 띄우고 사라집니다. 눈 깜빡할 만큼만요. 작업을 가리지 않고, 클릭도 그대로 통과합니다.

이런 분께 좋아요
• 한/영 전환이 잦은 개발자, 작가, 번역가
• 일본어·중국어 등 여러 입력기를 함께 쓰는 분
• 메뉴바 아이콘보다 화면 가운데를 더 오래 보는 분

할 수 있는 것
• 마우스가 있는 화면에, 전체화면 앱 위와 모든 Space에서 표시
• 표시 시간 0.5–5초
• 9군데 위치 중 고르거나, 끌어서 원하는 자리에
• 테마: 기본, 고대비, Dracula, Gruvbox, Rosé Pine, 나만의 색
• 크기·모서리·글자 굵기, '바뀐 언어만 보기'
• 손쉬운 사용의 투명도 줄이기·동작 줄이기를 따름
• 로그인할 때 자동 실행(원할 때만)

개인정보
Blink는 아무것도 수집하지 않고, 인터넷에 접속하지 않으며, 특별한 권한도 요구하지 않습니다. 현재 입력 언어의 이름만 읽습니다.

지원 언어: 영어, 한국어, 일본어, 중국어(간체·번체), 러시아어, 독일어, 프랑스어, 스페인어, 포르투갈어(브라질).

## 심사 노트 번역 (참고용, 입력 안 함)

`en-US/metadata.md`의 심사 노트를 옮긴 것이다.

Blink는 Dock 아이콘이 없는 메뉴바 앱입니다. 키보드 입력소스가 바뀔 때마다 화면에 짧은 HUD를 띄웁니다.

중요: HUD는 입력소스가 실제로 바뀔 때만 뜹니다. 심사용 Mac에 입력소스가 하나뿐이면 아무것도 뜨지 않으니 먼저 하나를 추가해 주세요.

1. 시스템 설정 > 키보드 > 입력 소스 > 편집…을 엽니다.
2. "+"를 눌러 한국어 > 2벌식(다른 언어도 됩니다)을 고르고 추가를 누릅니다.
3. Control-Space(또는 메뉴바의 입력 메뉴, 설정해 두었다면 지구본·Caps Lock 키)로 입력소스를 전환합니다.
4. "변경 전 → 변경 후"(예: "ABC → 2벌식")를 보여 주는 HUD가 화면 가운데에 1초 동안 뜹니다.

설정: 처음 실행하면 설정 창이 자동으로 열립니다. 그 뒤에는 메뉴바의 Blink 아이콘(•→)을 눌러 "설정…"(⌘,)을 고릅니다. 설정은 일반(HUD 표시, 표시 시간, 로그인 시 실행)·위치·모양 세 화면입니다.

입력소스가 하나뿐이면 '위치' 화면에 HUD가 뜨지 않는다는 안내가 나옵니다.

로그인 시 실행은 SMAppService를 쓰며 기본 꺼짐이고, 사용자가 켤 때만 등록됩니다.

Blink는 App Sandbox에서 실행되고, 네트워크에 접속하지 않으며, 데이터를 수집하지 않고, 어떤 권한(손쉬운 사용, 입력 모니터링)도 요청하지 않습니다. Text Input Sources API로 현재 입력소스 이름만 읽습니다.
