# 1.1.0 한국어 메타데이터

App Store Connect에서 언어를 한국어로 두고 붙여 넣는 문안. 스크린샷은 아래 '스크린샷' 표의 순서대로 올린다. 1.0.0과 달라진 곳은 이 버전의 업데이트 내용(새로 씀)과 설명의 '할 수 있는 것'·'개인정보'다.

## 이름 (30자)

Blink: 입력 언어 알림

## 부제 (30자)

한영 전환, 이제 눈으로 확인

## 키워드 (100자)

입력소스,한영키,자판,키보드,오타,한글,영문,메뉴바,IME,두벌식

## 프로모션 문구 (170자)

한영 전환이 제대로 됐는지 궁금한 순간, Blink가 화면에 바로 알려 줍니다. 위치와 디자인까지 내 취향대로 설정하세요.

## 이 버전의 업데이트 내용 (4000자)

1.1의 새로운 기능
• 표시 방식: 입력소스를 이름 그대로, 또는 "EN"·"한" 같은 약자로 보여 줍니다. 변경 전을 숨기면 약자 하나만 담은 작은 배지가 됩니다.
• Caps Lock HUD: Caps Lock을 누를 때마다 "⇪ 켜짐"·"⇪ 꺼짐"을 보여 줍니다. 설정 > 일반에서 켜세요.
• 포인터 배지: 마우스 포인터 옆에 지금 입력소스를 늘 붙여 둡니다. 붙는 방향과 크기를 고르고, 포인터가 멈추면 숨길 수도 있습니다. 설정 > 포인터에서 켜세요.
• 변경 전을 숨기면 화살표도 함께 숨깁니다.

여전히 특별한 권한은 필요 없습니다.

## 심사 노트 번역 (참고용, 입력 안 함)

`en-US/metadata.md`의 심사 노트를 옮긴 것이다.

Blink는 Dock 아이콘이 없는 메뉴바 앱입니다. 키보드 입력소스가 바뀔 때마다 화면에 짧은 HUD를 띄웁니다.

중요: HUD는 입력소스가 실제로 바뀔 때만 뜹니다. 심사용 Mac에 입력소스가 하나뿐이면 아무것도 뜨지 않으니 먼저 하나를 추가해 주세요.

1. 시스템 설정 > 키보드 > 입력 소스 > 편집…을 엽니다.
2. "+"를 눌러 한국어 > 2벌식(다른 언어도 됩니다)을 고르고 추가를 누릅니다.
3. Control-Space(또는 메뉴바의 입력 메뉴, 설정해 두었다면 지구본·Caps Lock 키)로 입력소스를 전환합니다.
4. "변경 전 → 변경 후"(예: "ABC → 2벌식")를 보여 주는 HUD가 화면 가운데에 1초 동안 뜹니다.

설정: 처음 실행하면 설정 창이 자동으로 열립니다. 그 뒤에는 메뉴바의 Blink 아이콘(•→)을 눌러 "설정…"(⌘,)을 고릅니다. 설정은 일반·위치·모양·포인터 네 화면입니다.

1.1.0의 새 기능(모두 기본 꺼짐):
• 모양 > 표시 방식 > 약자: 이름 대신 "EN" 같은 약자로 보여 줍니다.
• 일반 > Caps Lock HUD 표시: Caps Lock을 누르면 "⇪ 켜짐"·"⇪ 꺼짐"을 보여 줍니다. NSEvent.modifierFlags로 Caps Lock 상태만 읽고, 키 입력은 감시하지 않습니다.
• 포인터 > 포인터 옆 입력소스 표시: 마우스 포인터 옆에 현재 입력소스를 담은 작은 배지를 붙여 둡니다. 마우스 이동 이벤트(마우스 이벤트만 받는 NSEvent 전역 모니터)와 NSEvent.mouseLocation을 씁니다.

입력소스가 하나뿐이면 '위치' 화면에 HUD가 뜨지 않는다는 안내가 나옵니다.

로그인 시 실행은 SMAppService를 쓰며 기본 꺼짐이고, 사용자가 켤 때만 등록됩니다.

Blink는 App Sandbox에서 실행되고, 네트워크에 접속하지 않으며, 데이터를 수집하지 않고, 어떤 권한(손쉬운 사용, 입력 모니터링)도 요청하지 않습니다. Text Input Sources API로 현재 입력소스를, 위에 적은 대로 Caps Lock 상태와 포인터 위치를 읽습니다.
