# 1.4.0 한국어 메타데이터

App Store Connect에서 언어를 한국어로 두고 붙여 넣는 문안. 섹션은 App Store Connect의 macOS 앱 버전 화면에 나오는 순서대로 적었고, 이름·부제는 '앱 정보' 화면이라 맨 끝에 둔다. 1.3.0과 달라진 곳은 스크린샷 표(4장 모두 새로 만듦), 프로모션 텍스트, 설명의 '할 수 있는 것' 포인터 배지·통계·타이핑 줄과 '개인정보', 이 버전의 업데이트 내용(새로 씀), 키워드(타자·타수 추가), 버전·빌드, 심사 노트(설정 화면 구성, '1.4.0의 새 기능', 이전 기능을 4,000자 안으로 줄임, 마지막 문단)다.

한영 전환이 제대로 됐는지 궁금한 순간, Blink가 화면에 바로 알려 줍니다. 하루에 몇 번 바꾸고 몇 번 쳤는지도 세어 드려요. 위치와 디자인은 내 취향대로.

개인정보
Blink는 아무것도 수집하지 않고, 인터넷에 접속하지 않습니다. 화면에 그리기 위해 현재 입력 언어, Caps Lock 상태, 포인터 위치를 읽습니다. 통계는 입력소스 전환과 포인터 이동·클릭·스크롤을 세고, 이 Mac 안에만 남습니다. 타이핑 통계는 직접 켜기 전까지 꺼져 있습니다. 켜면 입력 모니터링 권한이 필요하고, 누른 키의 개수만 셀 뿐 어떤 키를 눌렀는지, 무엇을 입력했는지는 기록하지 않습니다. 통계는 언제든 끄거나 지울 수 있습니다.

지원 언어: 영어, 한국어, 일본어, 중국어(간체·번체), 러시아어, 독일어, 프랑스어, 스페인어, 포르투갈어(브라질).

## 4. 이 버전에서 업그레이드된 사항 (4000자)

1.4의 새로운 기능
• 타이핑 통계: 키 입력 횟수와 분당 키 입력을 입력소스별·앱별로 봅니다. 설정 > 통계에서 켭니다. 입력 모니터링 권한을 묻고, 누른 키의 개수만 셀 뿐 입력한 내용은 기록하지 않습니다.
• 오늘을 한눈에: 메뉴 맨 위에 오늘의 한/영 전환, 타이핑, 포인터 사용이 보입니다.
• 포인터 배지: 언제 보일지 고릅니다(항상·움직일 때·클릭할 때). 이제 기본으로 클릭한 자리에 잠깐 보이고, 메뉴바와 Dock 위에서는 숨습니다.
• 설정 사이드바를 기능별로 묶었습니다: 일반, 입력소스 HUD, 포인터 배지, 통계.

쓰던 설정은 그대로 이어집니다. 포인터 배지를 쓰고 있다면 설정 > 포인터 배지 > 배지 보기에서 언제 보일지 바꿀 수 있습니다.

## 7. 앱 심사 정보 > 메모 (번역, 참고용, 입력 안 함)

`en-US/metadata.md`의 심사 노트를 옮긴 것이다.

Blink는 Dock 아이콘이 없는 메뉴바 앱입니다. 키보드 입력소스가 바뀔 때마다 화면에 짧은 HUD를 띄웁니다.

중요: HUD는 입력소스가 실제로 바뀔 때만 뜹니다. 심사용 Mac에 입력소스가 하나뿐이면 아무것도 뜨지 않으니 먼저 하나를 추가해 주세요.

1. 시스템 설정 > 키보드 > 입력 소스 > 편집…을 엽니다.
2. "+"를 눌러 한국어 > 2벌식(다른 언어도 됩니다)을 고르고 추가를 누릅니다.
3. Control-Space(또는 메뉴바의 입력 메뉴, 설정해 두었다면 지구본·Caps Lock 키)로 입력소스를 전환합니다.
4. "변경 전 → 변경 후"(예: "ABC → 2벌식")를 보여 주는 HUD가 화면 가운데에 1초 동안 뜹니다.

설정: 처음 실행하면 설정 창이 자동으로 열립니다. 그 뒤에는 메뉴바의 Blink 아이콘(•→)을 눌러 "설정…"을 고릅니다. 사이드바는 일반, 입력소스 HUD(표시·위치·모양), 포인터 배지, 통계입니다.

1.4.0의 새 기능:
• 타이핑 통계(기본 꺼짐, 설정 > 통계 > 타이핑 통계). 사용자가 켤 때만 입력 모니터링 권한을 요청합니다(CGRequestListenEventAccess). 나머지 기능은 권한 없이 모두 동작합니다. 허용되면 keyDown만 받는 리슨 전용 이벤트 탭(CGEventTap, kCGSessionEventTap, kCGEventTapOptionListenOnly)을 만듭니다. 키를 누를 때마다 자동 반복 여부와 시각만 읽고 키 코드나 글자는 읽지 않으며, 현재 입력소스 ID와 맨 앞 앱의 번들 ID와 함께 개수를 하나 더합니다. 이것으로 입력소스별·앱별 키 입력과 분당 키 입력을 보여 줍니다. 끄면 탭을 바로 없앱니다. 손쉬운 사용 권한은 쓰지 않습니다.
• 확인 방법: 타이핑 통계를 켜고 시스템 설정 > 개인정보 보호 및 보안 > 입력 모니터링에서 Blink를 허용한 뒤(macOS가 Blink를 다시 열지 묻습니다) 아무 앱에서나 타이핑합니다. 메뉴와 "통계…"에 키 입력이 나옵니다. Blink 정보의 "타이핑 통계 켜기" 버튼도 같은 일을 합니다.
• 메뉴 맨 위에 오늘의 요약이 있습니다: 전환, 타이핑(켰을 때), 포인터 사용.
• 포인터 배지 > 배지 보기: 항상, 움직일 때, 클릭할 때(기본). 메뉴바와 Dock 위에서는 배지를 숨깁니다.

이전 기능:
• 통계(1.3.0, 기본 켜짐)는 입력소스 전환과 포인터 사용을 셉니다. 포인터 사용은 마우스 이벤트만 받는 NSEvent 전역 모니터로 받고, 거리는 CGDisplayScreenSize로 셉니다. 기록은 90일 동안 한 시간 합계, 그 뒤로는 하루 합계이고(앱별 키 입력은 하루 합계 90일), 샌드박스 컨테이너의 Statistics.json에 있습니다. 설정 > 통계에서 모으기를 끄고 모두 지울 수 있습니다.
• Blink 정보는 업데이트 뒤 한 번 열리고, 새로 설치했을 때는 열리지 않습니다.
• 기본 꺼진 선택 기능: 약자 표시(모양 > 표시 방식), Caps Lock HUD(표시, NSEvent.modifierFlags만 읽음), 포인터 배지(포인터 배지, 마우스 이벤트와 NSEvent.mouseLocation). macOS 26에서 기본 테마는 Liquid Glass를 쓰고, 클래식은 예전 모습입니다.
• 로그인 시 실행은 SMAppService를 쓰며 기본 꺼짐입니다.

Blink는 App Sandbox에서 실행되고, 네트워크에 접속하지 않으며, 데이터를 수집하지 않습니다. 요청하는 권한은 입력 모니터링 하나뿐이고, 사용자가 타이핑 통계를 켤 때만 요청합니다. 키 입력 횟수와 앱 번들 ID를 포함한 통계는 기기 밖으로 나가지 않으므로 App 개인정보 보호 답변은 "데이터를 수집하지 않음" 그대로입니다.
