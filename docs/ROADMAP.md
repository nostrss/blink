# Blink 로드맵

단계마다 끝나면 빌드하고, 완료 기준을 직접 확인한 다음 다음 단계로 넘어간다. 설계 근거는 [ADR 0001](adr/0001-app-sandbox-from-start.md), UI 값은 [디자인 시스템](https://claude.ai/artifact/3n9WYkuynDn61C23fgZ8Nw)을 따른다.

## 0. 프로젝트 설정

- 멀티플랫폼 템플릿을 macOS 전용으로 바꾼다 (`SDKROOT = macosx`, iOS·visionOS 설정 제거).
- 배포 타깃 26.6 → 13.0 (`SMAppService`의 최소 버전).
- 번들 ID `com.jintaek.Blink` → `com.jintaek.blink`.
- `LSUIElement = YES`로 Dock 아이콘을 없앤다. 쓰지 않는 파일 접근 엔타이틀먼트는 제거한다.
- SwiftUI 템플릿을 AppKit `AppDelegate`로 교체하고 `ContentView.swift`를 삭제한다.

**완료 기준**: 빌드가 되고, 실행하면 Dock 아이콘과 창 없이 프로세스만 떠 있다.

## 1. 메뉴바 골격

- `NSStatusItem`에 `menubar-icon.svg`를 템플릿 이미지로 넣는다.
- 메뉴: "언어 전환 표시"(체크), "로그인 시 실행"(체크), "설정…"(⌘,), "정보…", 구분선, "Blink 종료". "설정…"은 4단계, "로그인 시 실행"·"정보…"는 5단계 전까지 비활성.
- 토글 상태는 `UserDefaults` 키 하나에 저장한다. 꺼지면 아이콘을 `appearsDisabled`로 표시한다.

**완료 기준**: 아이콘이 라이트/다크 모드에서 모두 보이고, 토글 상태가 재실행 후에도 유지되고, 종료가 동작한다.

## 2. 입력소스 감지

- `kTISNotifySelectedKeyboardInputSourceChanged`를 구독하고, 현재 입력소스의 로컬라이즈된 이름을 읽는다.
- 직전 값과 같으면 무시한다.

**완료 기준**: 샌드박스를 켠 상태에서 한/영을 전환할 때마다 "변경 전 → 변경 후"가 로그에 정확히 한 번 찍힌다.

## 3. HUD 오버레이

- 테두리 없는 투명 `NSPanel` 하나를 재사용한다. 최상위 레벨, 마우스 이벤트 무시, 모든 Space와 전체화면 위에 표시한다.
- 마우스가 있는 화면 중앙에 띄운다. 표시 시간(기본 1.0초) 동안 유지한 뒤 0.3초 동안 페이드아웃한다. 표시 시간은 `UserDefaults`에서 읽어 4단계에서 바로 연결할 수 있게 한다. 연속으로 전환되면 타이머만 리셋한다.
- 색·글꼴·간격·모서리는 디자인 시스템의 `hud-*` 토큰을 쓴다.

**완료 기준**: 전환하면 HUD가 뜨고, 토글이 꺼져 있으면 뜨지 않는다.

## 4. 설정 창: 표시 시간

- 메뉴 "설정…"(⌘,)으로 여는 창에 "표시 시간" 입력란을 둔다. 숫자 입력 + 스테퍼, 단위 "초", 0.5–5.0초, 0.5초 단위, 기본 1.0초.
- 범위를 벗어나거나 숫자가 아닌 값은 가장 가까운 허용값으로 고친다. 저장 버튼 없이 바로 적용하고 `UserDefaults`에 저장한다.
- 페이드아웃 0.3초는 고정이며 표시 시간에 포함하지 않는다.

**완료 기준**: 값을 바꾸면 다음 전환부터 HUD 유지 시간이 바뀌고, 재실행 후에도 유지되며, 잘못된 입력은 허용 범위로 고쳐진다.

## 5. 자동 실행과 정보·첫 실행 창

- 로그인 항목은 `SMAppService.mainApp`으로, 사용자가 켤 때만 등록한다(기본 꺼짐). App Store 심사 가이드라인 2.4.5(iii)가 동의 없는 자동 실행을 금지하기 때문이다.
- "로그인 시 실행" 체크 상태는 저장하지 않고 매번 `SMAppService.mainApp.status`에서 읽는다(시스템 설정에서 끌 수 있으므로).
- 첫 실행 창에 "로그인 시 자동으로 실행" 체크박스를 둔다.
- 정보·첫 실행 창: "무엇을 하는 앱인지 + 켜고 끄는 법"만 담는다. App Store 심사에도 필요하다.

**완료 기준**: 켰을 때만 재로그인 후 자동으로 실행되고, 시스템 설정에서 끄면 메뉴 체크도 풀려 있으며, 첫 실행 때만 안내 창이 뜨며, "정보…"로 다시 열 수 있다.

## 6. 검증

- 순수 로직(중복 전환 걸러내기, 표시 시간 보정, HUD 폭 계산)은 단위 테스트 타깃 `BlinkTests`로 검증한다.
- 나머지는 [CHECKLIST.md](CHECKLIST.md)를 따른다. 한/영 전환, 표시 시간 최소·최대값, 세 번째 입력소스 추가, 전체화면 앱 위, 멀티 모니터(마우스가 있는 화면), 토글 off, 빠른 연속 전환, 라이트/다크 모드가 들어 있다.

**완료 기준**: 단위 테스트가 통과하고, 체크리스트 전체를 한 번 확인한다.

## 7. Mac App Store 출시

App Store Connect에 앱 등록 → Archive → App Store Connect 업로드 → 스크린샷·설명·개인정보 처리방침 URL → 심사 노트에 동작 방식 설명 → 제출. 업데이트도 같은 경로로 올리며, 사용자 쪽 자동 업데이트는 스토어가 처리한다.

**완료 기준**: 심사를 통과하고 스토어에서 설치된다.
