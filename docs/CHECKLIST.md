# Blink 검증 체크리스트

언제 확인하나:

- **코드를 바꿀 때마다**: 단위 테스트(`BlinkTests`)를 돌린다.
- **영역 코드를 바꿨을 때**: 아래에서 그 영역 항목만 확인한다.
- **App Store 제출 전**(첫 출시와 업데이트마다): 전체를 확인한다.

확인 주체: **Claude**는 스크립트(`TISSelectInputSource`, `screencapture`, `osascript`)로 확인할 수 있는 항목, **사용자**는 키보드·시스템 설정·하드웨어가 필요한 항목이다. 단위 테스트로 덮이는 항목은 (테스트)로 표시한다.

## 입력소스 감지

- [ ] 한/영 전환마다 HUD가 정확히 한 번 뜬다. (Claude: 스크립트 전환 / 사용자: 한/영 키)
- [ ] 같은 입력소스를 다시 선택하면 아무 일도 없다. (테스트)
- [ ] 세 번째 입력소스(예: 일본어)를 추가해도 전환마다 이름이 맞게 나온다. (사용자)
- [ ] App Sandbox가 켜진 빌드에서 동작한다(`codesign -d --entitlements -`로 `app-sandbox = true`). (Claude)

## HUD

- [ ] 마우스가 있는 화면의 표시 위치에 뜬다. 멀티 모니터에서 마우스를 옮겨 가며 확인. (사용자)
- [ ] 표시 위치 계산: 9방위 프리셋이 여백 24pt 안에 붙고, 메뉴바·Dock 위로 나가지 않으며, HUD가 영역보다 넓으면 가운데에 놓인다. (테스트)
- [ ] 왼쪽 위·가운데·오른쪽 아래를 골랐을 때 실제 HUD가 그 자리에 뜬다. (Claude 캡처)
- [ ] 해상도가 다른 외장 모니터에서도 같은 비율의 자리에 뜬다. (사용자)
- [ ] 전체화면 앱 위, 다른 Space에서도 뜬다. (사용자)
- [ ] 표시 시간 동안 머문 뒤 0.3초 페이드아웃된다. (Claude)
- [ ] 빠르게 연속 전환하면 깜빡이지 않고 글자만 바뀌며 타이머가 리셋된다. (Claude)
- [ ] 클릭이 HUD를 통과한다. (사용자)
- [ ] 폭은 최대 480pt, 넘치면 '변경 전'만 말줄임, '변경 후'는 자르지 않는다. (테스트 + Claude 캡처)
- [ ] 라이트/다크 모드 모두 디자인 시스템 색으로 보인다. 모서리 밖에 네모가 비치지 않는다(각지게·기본·알약 모두). (사용자)
- [ ] 시스템 모드를 바꾸면 다음 HUD부터 그 모드의 테마 색으로 뜬다. (사용자)
- [ ] 손쉬운 사용 > 투명도 줄이기를 켜면 배경이 불투명해진다(기본 테마는 surface, 다른 테마는 같은 색을 불투명하게). 규칙은 (테스트), 화면은 (사용자)
- [ ] 손쉬운 사용 > 동작 줄이기를 켜면 페이드 없이 표시 시간 + 0.3초 후 사라진다. (사용자)
- [ ] "언어 전환 HUD 표시"를 끄면 HUD가 뜨지 않는다. (Claude)

## 설정 창

- [ ] 메뉴 "설정…"(⌘,)으로 열리고 앞으로 나오며, 항상 '일반'부터 보인다. (Claude)
- [ ] 왼쪽 사이드바(일반·위치·모양, 아이콘 없음)를 누르면 오른쪽 내용과 창 제목이 바뀐다. 사이드바는 접히지 않는다. (Claude)
- [ ] 처음 열 때(저장된 창 크기가 없을 때) 높이는 '모양'의 사용자 지정 색 줄까지 스크롤 없이 들어가는 높이이고, 화면보다 크면 화면 높이에 맞춘다. 언어마다 높이가 다를 수 있다. (Claude: `-"NSWindow Frame Settings" ""` 인자로 실행)
- [ ] 창을 가로세로로 늘이고 줄일 수 있고, 620×440보다 작아지지 않는다. 늘린 만큼 내용 영역이 커지고 사이드바는 180pt 그대로다. 다시 열면 마지막 크기·자리로 열린다. (Claude + 사용자: 재실행)
- [ ] ⌘W로 닫힌다. (사용자)
- [ ] 라이트/다크 모드 모두 디자인 시스템 색으로 보인다. (Claude 캡처)

### 일반

- [ ] '언어 전환 HUD 표시' 스위치를 끄면 HUD가 뜨지 않고 메뉴바 아이콘이 바로 흐려진다. 다시 켜면 돌아온다. 재실행 후에도 유지된다. (Claude)
- [ ] '로그인 시 실행' 스위치는 기본 꺼짐이고, 켜면 `SMAppService.mainApp.status`가 enabled가 된다. (Claude)
- [ ] 시스템 설정 > 일반 > 로그인 항목에서 끈 뒤 설정 창을 다시 앞으로 가져오면 스위치도 꺼져 있다. (사용자)
- [ ] 입력란은 값을 보여 주기만 하고 직접 입력·선택할 수 없다. 스테퍼로만 0.5초 단위로 바뀌고, 0.5에서 내리거나 5.0에서 올리면 그 자리에 멈춘다(반대쪽 끝으로 넘어가지 않는다). 설정은 (테스트), 화면은 (Claude)
- [ ] 스테퍼로 바꾸면 다음 전환부터 HUD 유지 시간이 바뀐다. (사용자)
- [ ] '일반'에는 도움말 문구가 없다. (Claude)
- [ ] 재실행 후에도 표시 시간이 유지된다. (사용자)

### 위치

- [ ] 처음에는 가운데이고 "기본값으로" 버튼이 비활성이다. (Claude)
- [ ] 미니 모니터 위쪽에 메뉴바 스켈레톤(왼쪽: 점 1개와 메뉴 막대 3개, 오른쪽: 점 2개와 시계 막대)이 보이고, 미니 모니터 폭을 줄여도 양쪽이 겹치지 않는다. (Claude: 라이트 / 사용자: 다크)
- [ ] 미니 모니터는 16:10을 지키며 내용 폭을 채우고, 창이 낮으면 높이에 맞춰 줄어든다. 창이 저절로 커지지 않는다. (Claude)
- [ ] 미니 HUD가 현재 모양(테마, 크기, 모서리, 굵기, 표시 방식, 변경 전 표시)으로 그려지고, '모양'에서 바꾼 뒤 '위치'로 오면 바뀐 모양으로 보인다. 크기가 바뀌어도 위치(비율)는 그대로다. (Claude)
- [ ] 미니 HUD 왼쪽은 현재 입력소스, 오른쪽은 다음에 바뀔 입력소스(직전에 쓰던 것, 없으면 키보드 설정 목록에서 현재가 아닌 첫 번째)다. 고르는 규칙은 (테스트), 화면은 (Claude)
- [ ] 설정 창이 열려 있는 동안 입력소스를 바꾸면 미니 HUD 이름이 바로 바뀐다. (사용자)
- [ ] 입력소스가 하나뿐이면 오른쪽에 "없음"이 흐리게 나오고, 아래에 입력소스를 추가하라는 안내가 보인다. 둘 이상이면 안내가 사라진다. (사용자: 시스템 설정 > 키보드 > 입력 소스에서 하나만 남기고 확인)
- [ ] 점을 누르면 미니 HUD가 그 자리로 가고, 아래 이름이 프리셋 이름으로 바뀌며, 실제 화면에 HUD가 미리 뜬다. (Claude)
- [ ] 미니 HUD를 끌면 따라오고, 끄는 동안 실제 HUD도 따라 움직인다. 놓으면 저장되고 이름이 "직접 지정"이 된다. (사용자)
- [ ] 프리셋 점에 가까이(12pt) 끌면 그 점에 붙고 프리셋 이름으로 바뀐다. 끌어도 미니 모니터 밖으로 나가지 않는다. (테스트 + 사용자)
- [ ] "언어 전환 HUD 표시"가 꺼져 있어도 위치를 고르는 동안에는 미리보기가 뜬다. (Claude)
- [ ] "기본값으로"를 누르면 가운데로 돌아온다. 재실행 후에도 고른 위치가 유지된다. (Claude)
- [ ] 키보드 전체 접근을 켜면 Tab으로 점 사이를 오가고 Space로 고를 수 있다. VoiceOver가 점의 이름을 읽는다. (사용자)

### 모양

- [ ] 처음에는 테마 기본·크기 보통·모서리 기본·굵기 보통·표시 방식 이름·변경 전 표시 켜짐이고 "기본값으로"가 비활성이다. (Claude)
- [ ] 위쪽 라이트·다크 미리보기가 지금 설정 그대로 그려지고, 값을 바꾸면 바로 바뀐다. (Claude)
- [ ] 값을 바꾸면 실제 화면의 저장된 표시 위치에 HUD가 지금 시스템 모드로 뜬다. (Claude)
- [ ] 테마 메뉴는 기본·고대비·Dracula·Gruvbox·Rosé Pine, 구분선, 사용자 지정 순서이고, 항목마다 테마 배경에 화살표 색 견본이 있다. (Claude)
- [ ] 프리셋 글자는 라이트·다크 모두 배경과 4.5:1, 화살표는 3:1 이상이다. (테스트)
- [ ] 프리셋을 고른 상태에서는 색 편집 줄이 보이지 않는다. (Claude)
- [ ] 프리셋에서 사용자 지정으로 바꾸면 그 프리셋의 색(변경 전·화살표 포함, 예: Dracula의 보라·분홍)과 모습을 그대로 이어받아, 바꾸는 순간 HUD가 달라지지 않는다. 사용자 지정에 있는 동안 고친 색은 재실행 후에도 남고, 다른 프리셋을 고른 뒤 다시 사용자 지정으로 오면 그 프리셋에서 시작한다. (테스트 + Claude 캡처)
- [ ] 사용자 지정에서 미리보기 칸을 누르면 그 모드가 편집 대상이 되고(accent 테두리), 변경 전·화살표·변경 후·배경 색상과 배경 불투명도가 그 모드에만 적용된다. (사용자)
- [ ] 사용자 지정의 배경 불투명도는 흐림까지 함께 조절한다(흐림 = min(1, 불투명도 ÷ 0.55)). 55% 이상이면 프리셋처럼 흐림을 다 깔고, 그 아래로 내리면 흐림도 옅어져 0%면 판 없이 글자와 그림자만 남는다. 실제 HUD와 미리보기가 같게 보인다. 규칙은 (테스트), 화면은 (Claude 캡처)
- [ ] 변경 후나 변경 전 색상과 배경 색상 대비가 3:1보다 낮거나 배경 불투명도가 30% 미만이면 경고 문구가 보인다. 규칙은 (테스트), 화면은 (사용자)
- [ ] 손쉬운 사용 > 투명도 줄이기가 켜져 있으면 배경 불투명도 줄에서 슬라이더와 % 숫자가 사라지고 그 자리에 "투명도 줄이기 끄기 ↗" 링크가, 아래에 이유 한 문장이 보인다. 긴 언어(독일어·러시아어)에서는 링크가 오른쪽 정렬로 두 줄이 된다. 끄면 설정 창이 열린 채로 슬라이더와 저장된 값이 다시 나타난다. (Claude 캡처: 켜짐 상태, 사용자: 켜고 끄기)
- [ ] 링크를 누르면 시스템 설정의 손쉬운 사용 > 디스플레이가 열린다(macOS 26.6에서 확인). 다른 macOS 버전(13–15)에서는 최소한 손쉬운 사용 화면이 열린다. (Claude: 26.6 / 사용자: 다른 버전)
- [ ] 설정 창이 열린 채 입력소스를 바꾸면 미리보기 미니 HUD가 새 이름에 맞는 폭으로 다시 그려진다. 규칙은 (테스트), 화면은 (사용자)
- [ ] 크기 작게·크게, 모서리 각지게·알약, 굵게, 변경 전 표시 끔이 실제 HUD에 그대로 반영된다. 변경 전 표시를 끄면 화살표도 함께 사라지고 변경 후만 뜬다. (Claude 캡처)
- [ ] 표시 방식을 약자로 바꾸면 실제 HUD와 미리보기, '위치'의 미니 HUD가 "EN → 한"처럼 약자로 뜬다. (Claude 캡처)
- [ ] 약자 규칙(일본어 모드별 あ·ア·ｱ·Ａ, 한, 简, 繁, 그 밖은 언어 코드 대문자, 언어가 없으면 이름 첫 글자)과, 변경 전·변경 후 약자가 같으면(ABC → U.S.) 그 전환만 이름으로 보이는 규칙. (테스트)
- [ ] 약자 + 변경 전 표시 끔이면 약자 하나만 정사각형 배지로 뜨고, 모서리 알약이면 원이 된다. '위치'의 미니 HUD도 같은 모양이다. (Claude 캡처)
- [ ] 표시 방식이 생기기 전(1.0.0)에 저장한 모양을 그대로 읽고, 표시 방식은 이름이 된다. (테스트)
- [ ] 크게일 때 긴 이름도 최대 폭(624pt) 안에서 '변경 전'부터 말줄임한다. (테스트 + Claude 캡처)
- [ ] "기본값으로"를 누르면 모두 기본으로 돌아가고 사용자 지정 색도 지워진다. 재실행 후에도 고른 모양이 유지된다. (Claude)
- [ ] 최소 크기 창에서 내용이 넘치면 이 화면 안에서 스크롤된다. (Claude)

## 메뉴·로그인 항목

- [ ] 메뉴바 아이콘(`•→`)이 라이트/다크에서 보이고, 토글을 끄면 흐리게 보인다. (사용자)
- [ ] 앱 아이콘이 Finder에서 회색 판 없이 파란 판 `•→`로 보인다(`NSWorkspace.icon(forFile:)`로 추출). (Claude)
- [ ] 메뉴는 "설정…", "Blink 정보", 구분선, "Blink 종료"뿐이다. (Claude)
- [ ] 설정에서 "로그인 시 실행"을 켠 상태로 로그아웃 후 다시 로그인하면 자동 실행된다. (사용자)
- [ ] "Blink 종료"로 종료된다. (Claude)

## 정보 창·첫 실행

- [ ] 메뉴 "Blink 정보"로 열리고, 앱 아이콘·"Blink"·"버전 X.Y.Z"(`MARKETING_VERSION`과 같은 값)만 가운데에 보인다. (Claude 캡처)
- [ ] 버전이 `MAJOR.MINOR.PATCH` 형식이다(`CFBundleShortVersionString`). (Claude)
- [ ] 창이 앞으로 나오고, Esc·⌘W로 닫힌다. (사용자)
- [ ] 처음 실행하면 설정 창이 '일반'으로 열리고, '로그인 시 실행'은 꺼져 있다. 두 번째 실행부터는 열리지 않는다. (Claude: `open -n Blink.app --args -didShowWelcome NO`로 첫 실행처럼 띄운 뒤, 인자 없이 다시 실행)

## 현지화

지원 언어 10개: 영어(기본), 한국어, 일본어, 중국어 간체·번체, 러시아어, 독일어, 프랑스어, 스페인어, 포르투갈어(브라질). 언어를 바꿔 실행: `open -n Blink.app --args -AppleLanguages "(de)"`.
