# Blink 검증 체크리스트

언제 확인하나:

- **코드를 바꿀 때마다**: 단위 테스트(`BlinkTests`)를 돌린다.
- **영역 코드를 바꿨을 때**: 아래에서 그 영역 항목만 확인한다.
- **App Store 제출 전**(첫 출시와 업데이트마다): 전체를 확인한다.

확인 주체: **Claude**는 스크립트(`TISSelectInputSource`, `screencapture`, `osascript`)로 확인할 수 있는 항목, **사용자**는 키보드·시스템 설정·하드웨어가 필요한 항목이다. 단위 테스트로 덮이는 항목은 (테스트)로 표시한다.

## 입력소스 감지

- [ ] 한/영 전환마다 HUD가 정확히 한 번 뜬다. (Claude: 스크립트 전환 / 사용자: 한/영 키)
- [ ] 같은 입력소스를 다시 선택하면 아무 일도 없다. (테스트)
- [ ] 세 번째 입력소스(예: 일본어)를 추가해도 전환마다 이름이 맞게 나온다. (사용자)
- [ ] App Sandbox가 켜진 빌드에서 동작한다(`codesign -d --entitlements -`로 `app-sandbox = true`). (Claude)

## HUD

- [ ] 마우스가 있는 화면의 중앙에 뜬다. 멀티 모니터에서 마우스를 옮겨 가며 확인. (사용자)
- [ ] 전체화면 앱 위, 다른 Space에서도 뜬다. (사용자)
- [ ] 표시 시간 동안 머문 뒤 0.3초 페이드아웃된다. (Claude)
- [ ] 빠르게 연속 전환하면 깜빡이지 않고 글자만 바뀌며 타이머가 리셋된다. (Claude)
- [ ] 클릭이 HUD를 통과한다. (사용자)
- [ ] 폭은 최대 480pt, 넘치면 '변경 전'만 말줄임, '변경 후'는 자르지 않는다. (테스트 + Claude 캡처)
- [ ] 라이트/다크 모드 모두 디자인 시스템 색으로 보인다. 모서리 밖에 네모가 비치지 않는다. (사용자)
- [ ] 손쉬운 사용 > 투명도 줄이기를 켜면 배경이 불투명해진다. (사용자)
- [ ] 손쉬운 사용 > 동작 줄이기를 켜면 페이드 없이 표시 시간 + 0.3초 후 사라진다. (사용자)
- [ ] "언어 전환 표시"를 끄면 HUD가 뜨지 않는다. (Claude)

## 설정 창

- [ ] 메뉴 "설정…"으로 열리고 앞으로 나온다. (사용자)
- [ ] 스테퍼와 입력란이 같은 값을 보이고, 바꾸면 다음 전환부터 HUD 유지 시간이 바뀐다. (사용자)
- [ ] 0.5 미만, 5.0 초과, 0.5 단위가 아닌 값, 숫자가 아닌 값이 허용값으로 고쳐진다. (테스트)
- [ ] 재실행 후에도 값이 유지된다. (사용자)

## 메뉴·로그인 항목

- [ ] 메뉴바 아이콘이 라이트/다크에서 보이고, 토글을 끄면 흐리게 보인다. (사용자)
- [ ] "언어 전환 표시" 상태가 재실행 후에도 유지된다. (Claude)
- [ ] "로그인 시 실행"을 켜면 체크되고, 끄면 해제된다. 체크는 `SMAppService.mainApp.status`를 읽은 값이다. (Claude)
- [ ] 켠 상태에서 로그아웃 후 다시 로그인하면 자동 실행된다. (사용자)
- [ ] 시스템 설정 > 일반 > 로그인 항목에서 끄면 메뉴 체크도 풀린다. (사용자)
- [ ] "Blink 종료"로 종료된다. (Claude)

## 정보·첫 실행 창

- [ ] 첫 실행에만 안내 창이 뜨고, "로그인 시 자동 실행" 체크박스는 기본 해제다. (사용자: 새 사용자 계정이나 앱 데이터 초기화 후)
- [ ] 메뉴 "정보…"로 다시 열린다. 체크박스는 없다. (Claude)
- [ ] 상태 카드가 현재 켜짐/꺼짐을 보인다. (Claude)
- [ ] 창이 앞으로 나오고, Return·Esc로 닫힌다. (사용자)
