# Blink 검증 체크리스트

단위 테스트로 확인할 수 없는 화면·시스템 동작만 적는다. 모든 항목은 Claude가 스크립트(`TISSelectInputSource`, `IOHIDSetModifierLockState`, CGEvent 마우스 이동·클릭, `screencapture`, `osascript`)로 직접 확인한다.

언제 확인하나:

- **코드를 바꿀 때마다**: 단위 테스트(`BlinkTests`)를 돌린다. 계산과 규칙(표시 위치, 폭, 색 대비, 약자, 유리 사용 여부, 설정 값 읽기)은 테스트가 지킨다.
- **영역 코드를 바꿨을 때**: 그 영역의 항목만 확인한다.
- **App Store 제출 전**: 전부 확인한다.

라이트/다크는 시스템 설정을 바꾸지 않고 `open -n Blink.app --args -AppleInterfaceStyle Dark`처럼 앱 인자로 확인한다.

## HUD

- [ ] 한/영 전환마다 HUD가 정확히 한 번, 마우스가 있는 모니터의 표시 위치에 뜨고 표시 시간 뒤 사라진다. 빠르게 연속 전환하면 깜빡이지 않고 글자만 바뀐다. 모니터 두 대에서 확인.
- [ ] 전체화면 앱 위와 다른 Space에서도 HUD와 포인터 배지가 뜬다.
- [ ] HUD 위를 클릭하면 그 아래 앱이 클릭을 받는다.
- [ ] 라이트/다크 모두 HUD가 디자인 시스템 색으로 보이고 모서리(각지게·기본·알약) 밖에 네모가 비치지 않는다. 이름이 길면 '변경 전'만 말줄임된다.
- [ ] macOS 26의 기본 테마는 유리 판, 클래식은 흐림 판으로 보인다. 밝은 창과 어두운 창 위에서 글자가 읽히고, 테마를 바꿔 가며 띄워도 글자가 판 가운데에 있다.
- [ ] 'Caps Lock HUD 표시'를 켜면 Caps Lock을 켤 때 "⇪ 켜짐", 끌 때 "⇪ 꺼짐"이 뜨고, 끄면 뜨지 않는다.
- [ ] Caps Lock HUD·포인터 배지·통계 모으기를 켜도 권한 요청(손쉬운 사용·입력 모니터링) 창이 뜨지 않는다. 입력 모니터링 창은 '타이핑 통계'를 켤 때만 뜬다(`tccutil reset ListenEvent <번들 ID>` 뒤 앱을 다시 띄워 확인, Debug 빌드는 `com.jintaek.blink.dev`).

## 포인터 배지

- [ ] 켜면 포인터 옆에 현재 입력소스 약자가 붙고, 포인터를 움직이면 다른 모니터까지 따라가고, 메뉴바·Dock 위에서는 사라졌다가 벗어나면 다시 나타난다. 입력소스를 바꾸면 글자가 바로 바뀐다. 끄면 사라진다. '배지 보기'가 움직일 때면 멈춘 뒤 표시 시간이 지나 사라지고, 클릭할 때면 따라가지 않고 클릭한 자리에 머물다 표시 시간 뒤 사라진다(다른 곳을 누르면 그리로 옮겨 감). macOS 26의 기본 테마에서는 HUD처럼 유리 판이고, 한 글자면 원 가운데에 글자가 있으며 밝은·어두운 창 위에서 읽힌다.

## 설정 창

- [ ] 메뉴 '설정…'으로 앞으로 열리고 '일반'부터 보이며, 사이드바(일반 / 입력소스 HUD 머리글 › 표시·위치·모양 / 포인터 배지 / 통계)를 누르면 내용이 바뀌고 머리글은 눌리지 않는다. 최소 크기(620×440)에서 넘치는 내용은 스크롤된다.
- [ ] '모양'에서 테마·크기·모서리·표시 방식·변경 전 표시를 바꾸면 미리보기와 실제 HUD가 바로 바뀐다.
- [ ] '위치'에서 점을 누르면 미니 HUD와 실제 HUD가 그 자리에 뜬다. '포인터 배지'에서 점을 누르면 실제 배지가 그 자리로 옮겨 가고, '배지 보기'를 바꾸면 실제 배지가 바로 그 방식으로 바뀐다.
- [ ] 바꾼 설정이 재실행 후에도 유지되고, "기본값으로"를 누르면 되돌아간다.
- [ ] '로그인 시 실행'을 켜면 `SMAppService.mainApp.status`가 enabled가 된다.

## 통계

- [ ] 빈 기록으로 실행해 한/영 전환, 다른 앱 위 포인터 이동·클릭·스크롤을 하면 메뉴 카드와 통계 창(오늘·7일·30일) 숫자와 막대가 늘고, "Blink 종료" 뒤 다시 실행해도 남는다. 지난 기록을 넣으면(목데이터) 증감과 7일·30일 막대·눈금이 보인다.
- [ ] '통계 모으기'를 끄면 메뉴 카드와 그 아래 구분선이 사라지고 더 세지 않는다. '모두 지우기…'는 시트에서 '지우기'를 눌러야 0이 된다.
- [ ] '타이핑 통계'를 켜고 권한을 허용하면(macOS가 앱을 끄고 다시 연다) 다른 앱에서 누른 키가 요약 카드와 통계 창(키 입력·분당 키 입력·입력소스별·앱별)에 늘고, 키를 꾹 눌러 반복된 입력은 늘지 않는다. 꺼짐·거부면 같은 자리에 켜기 카드가 보이고, 메뉴 카드의 버튼을 누르면 메뉴가 닫히고 설정 '통계'가 열린다. 설정 '통계'의 권한 줄은 허용됨·허용 안 됨·허용됨 · 쓰지 않음으로 바뀐다.

## 메뉴·정보 창·첫 실행

- [ ] 메뉴는 요약 카드, 구분선, "통계…", "설정…", "Blink 정보", 구분선, "Blink 종료"이고(macOS 26에서는 네 항목 모두 아이콘), "Blink 종료"로 종료된다.
- [ ] "Blink 정보"에 앱 아이콘·"Blink"·"버전 X.Y.Z"(`MARKETING_VERSION`)와 'X.Y.Z의 새로운 기능' 목록이 보이고 Esc로 닫힌다. 입력 모니터링 권한이 없으면 타이핑 통계 줄 아래 [타이핑 통계 켜기]가 설명 폭으로 보이고, 누르면 설정 '통계'가 열리며, 권한이 있으면 버튼이 없다. 업데이트 후 첫 실행이면 이 창이 저절로 열리고, 같은 버전으로 다시 실행하면 열리지 않는다. (`--args -didShowWelcome YES -lastSeenVersion 1.2.0`으로 띄운 뒤 `-didShowWelcome YES`만 주고 다시 실행)
- [ ] 첫 실행이면 설정 창이 '일반'으로 열리고, 두 번째 실행부터는 열리지 않는다. (`--args -didShowWelcome NO`로 띄운 뒤 인자 없이 다시 실행)

## 현지화

- [ ] 독일어·러시아어로 실행하면(`--args -AppleLanguages "(de)"`) 메뉴 카드, 통계 창, 설정 창 여섯 화면, 정보 창의 글자가 잘리거나 겹치지 않는다. 지원하지 않는 언어면 영어로 나온다.

## 출시

- [ ] 빌드된 앱이 샌드박스로 서명되고(`codesign -d --entitlements -`에 `app-sandbox = true`), `Info.plist`에 `LSApplicationCategoryType`과 `ITSAppUsesNonExemptEncryption = NO`가, `Contents/Resources`에 `PrivacyInfo.xcprivacy`가 있다.
