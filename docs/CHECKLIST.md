# Blink 검증 체크리스트

단위 테스트로 확인할 수 없는 화면·시스템 동작만 적는다. 모든 항목은 Claude가 스크립트(`TISSelectInputSource`, `IOHIDSetModifierLockState`, CGEvent 마우스 이동·클릭, `screencapture`, `osascript`)로 직접 확인한다.

언제 확인하나:

- **코드를 바꿀 때마다**: 단위 테스트(`BlinkTests`)를 돌린다. 계산과 규칙(표시 위치, 폭, 색 대비, 약자, 유리 사용 여부, 설정 값 읽기)은 테스트가 지킨다.
- **영역 코드를 바꿨을 때**: 그 영역의 항목만 확인한다.
- **App Store 제출 전**: 전부 확인한다.

라이트/다크는 시스템 설정을 바꾸지 않고 `open -n Blink.app --args -AppleInterfaceStyle Dark`처럼 앱 인자로 확인한다.

## HUD

- [ ] 한/영 전환마다 HUD가 정확히 한 번, 마우스가 있는 모니터의 표시 위치에 뜨고 표시 시간 뒤 사라진다. 빠르게 연속 전환하면 깜빡이지 않고 글자만 바뀐다. 모니터 두 대에서 확인.
- [ ] 전체화면 앱 위와 다른 Space에서도 HUD와 포인터 배지가 뜬다.
- [ ] HUD 위를 클릭하면 그 아래 앱이 클릭을 받는다.
- [ ] 라이트/다크 모두 HUD가 디자인 시스템 색으로 보이고 모서리(각지게·기본·알약) 밖에 네모가 비치지 않는다. 이름이 길면 '변경 전'만 말줄임된다.
- [ ] macOS 26의 기본 테마는 유리 판, 클래식은 흐림 판으로 보인다. 밝은 창과 어두운 창 위에서 글자가 읽히고, 테마를 바꿔 가며 띄워도 글자가 판 가운데에 있다.
- [ ] 'Caps Lock HUD 표시'를 켜면 Caps Lock을 켤 때 "⇪ 켜짐", 끌 때 "⇪ 꺼짐"이 뜨고, 끄면 뜨지 않는다.
- [ ] Caps Lock HUD·포인터 배지·통계 모으기를 켜도 권한 요청(손쉬운 사용·입력 모니터링) 창이 뜨지 않는다.

## 포인터 배지

- [ ] 켜면 포인터 옆에 현재 입력소스 약자가 붙고, 포인터를 움직이면 다른 모니터·메뉴바·Dock 위까지 따라간다. 입력소스를 바꾸면 글자가 바로 바뀐다. 끄면 사라진다. macOS 26의 기본 테마에서는 HUD처럼 유리 판이고, 한 글자면 원 가운데에 글자가 있으며 밝은·어두운 창 위에서 읽힌다.

## 설정 창

- [ ] ⌘,로 앞으로 열리고 '일반'부터 보이며, 사이드바(일반·위치·모양·포인터·통계)를 누르면 내용이 바뀐다. 최소 크기(620×440)에서 넘치는 내용은 스크롤된다.
- [ ] '모양'에서 테마·크기·모서리·표시 방식·변경 전 표시를 바꾸면 미리보기와 실제 HUD가 바로 바뀐다.
- [ ] '위치'에서 점을 누르면 미니 HUD와 실제 HUD가 그 자리에 뜬다. '포인터'에서 점을 누르면 실제 배지가 그 자리로 옮겨 간다.
- [ ] 바꾼 설정이 재실행 후에도 유지되고, "기본값으로"를 누르면 되돌아간다.
- [ ] '로그인 시 실행'을 켜면 `SMAppService.mainApp.status`가 enabled가 된다.

## 통계

- [ ] 빈 기록으로 실행해 한/영 전환, 다른 앱 위 포인터 이동·클릭·스크롤을 하면 메뉴 카드와 통계 창(오늘·7일·30일) 숫자와 막대가 늘고, "Blink 종료" 뒤 다시 실행해도 남는다. 지난 기록을 넣으면(목데이터) 증감과 7일·30일 막대·눈금이 보인다.
- [ ] '통계 모으기'를 끄면 메뉴 카드와 그 아래 구분선이 사라지고 더 세지 않는다. '모두 지우기…'는 시트에서 '지우기'를 눌러야 0이 된다.

## 메뉴·정보 창·첫 실행

- [ ] 메뉴는 통계 카드, 구분선, "통계…", "설정…", "Blink 정보", 구분선, "Blink 종료"이고, "Blink 종료"로 종료된다.
- [ ] "Blink 정보"에 앱 아이콘·"Blink"·"버전 X.Y.Z"(`MARKETING_VERSION`)가 보이고 Esc로 닫힌다.
- [ ] 첫 실행이면 설정 창이 '일반'으로 열리고, 두 번째 실행부터는 열리지 않는다. (`--args -didShowWelcome NO`로 띄운 뒤 인자 없이 다시 실행)

## 현지화

- [ ] 독일어·러시아어로 실행하면(`--args -AppleLanguages "(de)"`) 메뉴 카드, 통계 창, 설정 창 다섯 화면, 정보 창의 글자가 잘리거나 겹치지 않는다. 지원하지 않는 언어면 영어로 나온다.

## 출시

- [ ] 빌드된 앱이 샌드박스로 서명되고(`codesign -d --entitlements -`에 `app-sandbox = true`), `Info.plist`에 `LSApplicationCategoryType`과 `ITSAppUsesNonExemptEncryption = NO`가, `Contents/Resources`에 `PrivacyInfo.xcprivacy`가 있다.
